# 冲奖王国 · 局域网多人推理游戏

一个类狼人杀的局域网(LAN)多人推理游戏,C++17 编写,TCP 联机,跨平台(macOS / Linux / Windows),附带机器人陪玩(可接入 Claude API 让机器人真的会说话)和全自动测试模式。

## 快速开始

### macOS / Linux

```bash
make                # 编译出 server 和 client

# 房主(其中一台电脑):
./server            # 默认端口 5555;终端会打印本机局域网 IP
./server 5555 --bots 3   # 真人不够时用 3 个机器人补齐

# 其他玩家(同一局域网):
./client 192.168.x.x 5555 你的昵称

# 房主在自己的 client 里输入 start 开始游戏
# 纯机器人自动跑一局(测试/看规则演示):
./server --selftest 10
```

### Windows

1. 安装 MinGW-w64 的 g++(推荐 [winlibs.com](https://winlibs.com) 或 MSYS2),或使用 Visual Studio;
2. 双击或在 cmd 中运行 `build-windows.bat`,得到 `server.exe` / `client.exe`;
   - MSVC 用户:在 Developer Command Prompt 中执行
     `cl /std:c++17 /EHsc /utf-8 /O2 src\server.cpp /Fe:server.exe`(client 同理);
3. 用法与上面相同:`server.exe 5555 --bots 3`,`client.exe 192.168.x.x 5555 昵称`。
   建议用 Windows Terminal 运行(彩色和中文显示效果最好);第一次开服务端时防火墙弹窗选"允许"。

- 人数:4 人起(含机器人),推荐 8~16 人。
- 客户端看到黄色 `[ASK]` 提示时按提示输入(一般是座位号或 y/n);其他时候输入的内容作为聊天发出。
- 玩家掉线后由机器人接管,游戏继续。

### 让机器人真的会发言(可选,两种方式)

默认机器人只会说固定台词。配置 AI 后端后,机器人的白天发言和遗言会根据局势实时生成——
它们知道自己的身份和最近的公开信息,坏人会伪装带节奏,好人会分析推理。
两种后端按优先级选择,只需要**开服务端的那台电脑**配置(玩家客户端不用装任何东西):

**方式一:Ollama 本地模型(推荐,完全本地部署,不需要联网和 API Key)**

```bash
# 1. 安装 Ollama: https://ollama.com  然后拉一个中文能力好的模型
ollama pull qwen3:8b        # 或更小的 qwen3:4b; 显存大可用 gemma4 等

# 2. 设置 OLLAMA_MODEL 后开服 (默认连 http://127.0.0.1:11434, 可用 OLLAMA_HOST 覆盖)
export OLLAMA_MODEL=qwen3:8b            # Windows: set OLLAMA_MODEL=qwen3:8b
./server --selftest 8                   # 看8个AI机器人互相对喷一整局
```

思考型模型(qwen3 / gemma4 等)会自动关闭思考模式(`think:false`),保证出话快、
不吃 token;输出中的 `<think>` 残留也会被过滤。

**方式二:Claude API(云端)**

```bash
export ANTHROPIC_API_KEY=sk-ant-xxxx    # 在 platform.claude.com 申请
./server 5555 --bots 3
```

使用 `claude-haiku-4-5`(最便宜的快速模型,一句话约几厘钱)。

启用 AI 后,机器人的**发言、遗言、白天投票、夜晚技能目标、是否放技能**全部由模型决策:
每个机器人拿到自己的身份技能、坏人队友名单、收到过的私密信息(如推理结果)和最近的
公开局势作为上下文,按阵营利益行动——实测坏人会集火神职、必要时丢车保帅。

实现上都是通过系统自带的 `curl` 调 HTTP API,无第三方库依赖;后端不可用或调用失败时
自动退回本地台词和随机决策,不影响游戏。

## 阵营与胜利条件

| 阵营 | 胜利条件 |
|---|---|
| 好人阵营 | 清除所有坏人与第三方 |
| 坏人阵营 | 杀死所有好人 |
| 第三方 | 杀死其他所有人 |

## 发牌规则(补全)

设总人数为 N:

- 坏人数 = max(1, N/3),必含 1 名**人体拆卸者**,其余从坏人角色池随机;
- 第三方:N ≥ 8 时 1 名,从躺尸氢/潜伏者/木偶师中随机;
- 好人:必含**推理大师**和**药师**,其余从好人角色池随机,不够则补普通居民。

开局公示"板子"(本局包含哪些角色),但不公示对应到谁。

## 角色一览

### 好人阵营
| 角色 | 技能 |
|---|---|
| 冲奖王国居民 | 无技能 |
| 推理大师 | 每晚推理一人身份(好人/坏人/第三方) |
| 药师 | 一瓶毒药(杀人)+ 一瓶解药(救人),各一次 |
| 夺权者 | 第一夜选一人:好人则复制其技能;坏人/第三方则自己堕落为人体拆卸者 |
| 炮手 | 一次机会,白天发言前开炮杀一人;误杀好人则自己殉爆 |
| 千年生蚝精 | 硬壳可挡一次**夜晚物理伤害**(本人无察觉) |
| 不灭之神 | 两张长存符,夜晚首先睁眼选择是否使用;生效当晚+次日白天,除放逐外不死 |
| 天罚者 | 第三夜自动死亡;当晚首先看到所有坏人/第三方并杀死一人,随后死亡,无遗言 |
| Joker | 无技能,被推理大师推理时显示为坏人 |
| 投机者 | 好人占比 > 50% 时可跳槽坏人阵营,变为人体拆卸者 |
| 音波释放者 | 一次机会(非第一夜)释放音波,当晚坏人和第三方不可睁眼(技能全部失效) |
| 爆破者 | 一次机会,白天发言前选两人与自己同归于尽 |
| 修正者 | 一次机会:选一人,若为好人则自己死;否则对方公开身份并变为居民(转为好人阵营) |
| 破译者 | 一次机会:投票结束后使本次投票无效,由自己直接选择放逐对象 |

### 坏人阵营
| 角色 | 技能 |
|---|---|
| 人体拆卸者 | 每晚拆卸(杀死)一人 |
| 电脑吞食者 | 投票结束后可自暴:公开身份并死亡,直接杀死一人,立刻进入黑夜 |
| 天谴者 | 第一夜选一名好人,使其获得 Joker 效果(被推理显示坏人) |
| 宿管老师 | 一次机会(非第一夜)释放威压,当晚好人不可睁眼(技能全部失效) |
| 相思者 | 第一夜绑定一名好人/第三方;相思者死亡时被绑定者陪葬 |
| 窃取者 | 一次机会(夜晚):将一人变为无技能的冲奖王国居民 |
| 撕裂者 | 一次机会:用小说切断电脑,当天无法投票 |
| 雷电法王 | 一次机会(白天):当日投票给自己的**居民**全部死亡 |
| 空间拆卸者 | 一次机会(夜晚):选择相邻(顺时针挨着的)两人一起杀死 |
| 千年大瓜球 | 一次机会:有人被放逐后用瓜皮罩住其角色卡,使其无法明牌 |

### 第三方
| 角色 | 技能 |
|---|---|
| 躺尸氢 | 每晚选两人:直接杀死一人,另一人被打标记,下个夜晚死亡 |
| 潜伏者 | 坏人全灭前无技能;坏人全灭后每晚可杀一人。被推理大师推理时永远显示为好人 |
| 木偶师 | 每晚杀一人;第一晚选一名木偶,木偶死亡后下晚可重选;木偶师死亡时,木偶继承成为新的木偶师(转为第三方) |

## 流程规则(补全)

### 夜晚行动顺序
1. **不灭之神**首先睁眼,决定是否用长存符
2. 躺尸氢的旧标记发作
3. (仅第三夜)**天罚者**看到所有坏人/第三方,杀一人后死亡
4. **音波释放者**决定是否放音波 → 生效则本夜坏人+第三方全部跳过
5. **宿管老师**决定是否放威压 → 生效则本夜好人(药师/推理大师/投机者)全部跳过
6. (仅第一夜)夺权者 → 坏人互认 → 天谴者 → 相思者
7. 坏人阵营选择拆卸目标(拆卸者全灭时由其余坏人代行)
8. 空间拆卸者 / 窃取者(一次性技能)
9. 躺尸氢 / 木偶师 / 潜伏者(第三方行动)
10. **药师**看到今晚倒下的人,决定救人/毒人
11. **推理大师**推理一人身份
12. **投机者**决定是否跳槽

### 夜晚伤害结算
- **长存符**:挡住一切夜晚伤害(和次日白天伤害),只有放逐能杀;
- **生蚝壳**:只挡**物理**伤害(刀、杀),毒药和天罚挡不住;挡完即碎,本人无察觉;
- **解药**:可以救刀下、标记发作的人;救不了天罚者的自爆;
- 夜晚死亡在天亮时统一公布(顺序打乱),**夜晚死亡无遗言**。

### 白天流程
1. 公布昨夜死讯 → 胜负判定
2. **炮手** / **爆破者** 可在发言前发动技能
3. 全员依次发言(其他时间可自由打字聊天)
4. **修正者**可发动修正
5. **撕裂者**可切断电脑(跳过今天的投票)
6. **雷电法王**秘密宣告是否发动 → 全员 60 秒并行投票 → 票型公开 → 天雷结算
7. 得票最多者被放逐;**平票则无人被放逐**
8. **破译者**可推翻投票并亲自选人放逐
9. 被放逐者:**千年大瓜球**可罩牌 → 否则可自选是否明牌 → 留遗言(放逐无视长存符)
10. **电脑吞食者**可自暴 → 直接入夜

### 裁定细则(本实现的约定)
- 夺权者复制技能时,获得该角色**全新**的技能次数(如复制药师得到全新两瓶药);复制到 Joker 也继承其"被推理显示坏人"的效果。
- 天谴者/相思者不知道谁是好人,只能凭感觉选(不能选坏人队友);选错则效果按规则落空。
- 修正者修正成功、窃取者窃取成功后,目标都变成**好人阵营的普通居民**(可能因此改变阵营归属和胜负判定)。
- 投机者跳槽、夺权者堕落后,坏人阵营全员会收到新队友通报。
- 相思之链是单向的:相思者死→绑定者陪葬;绑定者死,相思者没事。
- 空间拆卸者的"相邻"按开局座位顺时针计算,跳过已死玩家。
- 雷电法王只劈"居民"(普通冲奖王国居民),神职投他不会死;技能宣告后即消耗,无人投他也不退回。
- 电脑吞食者自暴时可以吞任何人(不局限好人,吞错人算他倒霉)。
- 超过 30 个白天自动判平局(防止极端僵局)。
- 玩家超时未操作:可跳过的技能自动放弃,必选项随机选择,投票算弃票。

## 技术说明

- `src/server.cpp`:服务端 = 法官,持有全部游戏逻辑;每个客户端一个读线程,游戏主线程通过"提问-应答"(带超时)驱动流程;机器人玩家直接走随机决策。
- `src/client.cpp`:瘦客户端,一个线程收消息打印,主线程读键盘发送。
- `src/common.hpp`:跨平台 socket 封装(POSIX / Winsock)。
- `src/ai.hpp`:机器人 AI 发言,通过 curl 调 Ollama(本地)或 Claude API(云端),失败自动退回本地台词。
- CI(GitHub Actions)在 Ubuntu / macOS / Windows(MSVC) 上编译并跑一整局机器人对战。
- 协议:纯文本行协议。客户端首行 `JOIN 昵称`;服务端 `[ASK] ...` 开头的行表示需要输入;其余都是广播文本。
- 想改规则(角色池、坏人比例、超时时间等)直接改 `server.cpp` 顶部对应函数即可,逻辑都集中在 `assignRoles` / `nightPhase` / `dayPhase`。
